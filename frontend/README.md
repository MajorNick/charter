# Frontend

This is the primary delivery surface for the Charter MVP.

Near-term responsibilities:

- local CSV and JSON ingestion
- schema preview
- no-code transformation builder
- chart mapping and preview
- save, load, update, and clone flows for backend-stored templates
- frontend routing for public template URLs such as `/t/<ulid>`

Keep uploaded datasets client-side in Phase 1. The backend stores template configuration JSON, not user data files.
